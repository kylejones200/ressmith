Correlations Reference
----------------------

**PVT Correlations Implemented in PetroSmith:**

1. **Standing (1947)** - Oil FVF
2. **Beggs-Robinson (1975)** - Oil viscosity  
3. **Vasquez-Beggs (1980)** - Oil FVF (improved)
4. **Hall-Yarborough (1973)** - Gas Z-factor
5. **Lee-Gonzalez-Eakin (1966)** - Gas viscosity

**Flow Correlations:**

1. **Darcy (1856)** - Linear flow
2. **Vogel (1968)** - IPR for solution gas drive
3. **Fetkovich (1973)** - IPR for all drive mechanisms
4. **Hagedorn-Brown (1965)** - Multiphase flow in tubing
5. **Beggs-Brill (1973)** - Multiphase flow (directional wells)
